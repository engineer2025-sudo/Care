## Earlier dates

The available repository history begins on 2026-09-02, and the available GitHub release list has no release dated June 2026 or earlier. Earlier version numbers and dates are therefore not recorded here; they should be added only from an older repository export, release page, or archived build metadata rather than estimated.

## Transfer checklist

When copying the source to another repository, carry this file and `docs/REPOSITORY-TRANSFER.md` with the source. Update the platform versions and published date together when creating a new release. Keep the iOS build number and Android version code alongside their marketing versions.
