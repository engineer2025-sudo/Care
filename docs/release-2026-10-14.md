## What changed

All three platforms now support activity favorites and searchable/editable care notes with confirmed deletion. iOS/web ask before discarding changed edits. Android's explicit Cancel leaves the saved note unchanged. Existing records migrate without automatically resetting user data.

Android adds light/dark/system appearance, native themed dialogs, settings shortcuts and a two-row navigation layout when system fonts are large. Its emulator smoke checks favorite persistence, note edits, cancelled deletion, dark mode and 160% font navigation. The dark large-text screen was also visually reviewed.

Web now has an 11-activity catalog and isolated sessions, instead of six simultaneously mounted games. Five supported-choice/conversation activities join the existing six. Every session was checked at 320px with largest text; exiting restores focus and stops sound. Breathing does not require a hold. The production offline test exposed and fixed a cache mismatch caused by `Vary: Origin` on static assets. Tailwind/PostCSS and dependencies were updated to clear the audit findings.

## Build provenance

The packaging script requires successful CI, checks that executable/configuration/test sources match those runs, validates the Android Git blob and SHA-256, checks ZIP integrity and extracted file hashes, and validates the extracted Xcode project. Native README-only documentation updates are excluded from the compiled-source comparison and remain independently hashed in the archive. Each ZIP includes its own `BUILD_VERIFICATION.json` and checksum sidecar.

## Boundaries — still manual

These are development builds, not App Store/Play Store releases. iPhone installation still needs a compatible Mac/Xcode, your signing team and a connected device. The Android APK is debug-signed and debuggable; a changed CI debug certificate can require exporting data and uninstalling the previous development build before installing this one.

Physical BLE behavior, real Apple Intelligence availability/responses, intended-user accessibility testing, signing on the user's Mac and clinical effectiveness are not established by these checks. Apple Intelligence only runs through Apple's real framework on eligible enabled iOS 26+ hardware; Android has no substitute. Activities are optional enjoyment/practice, not validated dementia/autism treatments. No sample people, medications or generated vital signs are added.
