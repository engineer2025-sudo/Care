# Source update — October 18, 2026

## What changed

- Web visit-preparation PDFs now include a final reverse-side appendix with the exact selected data, section provenance labels, preparation timestamp, embedded CareSphere seal artwork, and a SHA-256 fingerprint of the selected report text.
- iOS and Android PDF renderers now add a final appendix with selected information and the same decorative stamp artwork. Android's PDF renderer also recognizes live Bluetooth heart-rate sections and keeps ungrouped, user-selected Android records visible in the appendix.
- The report preview explains how to duplex print the final appendix. Health sections remain opt-in. Personal content is HTML-escaped in the web PDF.
- The stamp is explicitly decorative. The SHA-256 digest fingerprints only the report text; it is not a PDF signature and does not authenticate a clinician, clinic, medical record, or person.
- iOS adds five App Intents/Shortcuts for Today, Activities, breathing, mood check-in, and visit preparation. Links are allow-listed, queued through onboarding/lock, and only navigate. Breathing is not started automatically; mood is not recorded; nothing is shared.
- iOS Settings explains how to find the shortcuts. The breathing shortcut now opens the activity rather than claiming to start it.
- Web version is 1.5.1. Native source project versions are iOS 3.8.0 (17) and Android 1.9.0 (11).
