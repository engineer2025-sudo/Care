## The 80-second app demo: action, result, meaning

| Relative time | Genuine action | Say, in your own words |
|---|---|---|
| 0–20s | Activities → Pattern Recall → Start pattern → watch → repeat the actual pads → continue/replay or stop | This is Pattern Recall. I watch the sequence, then repeat it. The activity waits for me; if I get it wrong, I can replay rather than race a clock. |

If one interaction takes longer, trim another—do not speed up all the footage until it becomes unreadable. A genuine mismatch in a game is acceptable; narrate replay calmly. Do not claim a match you did not make.

## Before recording

- Use fictional sample data and a visible “sample data” label in the video editor, outside the actual UI.
- Open the app in Chrome/Edge. Preload Activities and locate each section. Close settings, reminder toasts and unrelated browser tabs.
- Practice the true pad sequence. Do not replace it with fabricated animation.
- Keep system volume low. Stop audio before moving on.
- Use readable zoom and deliberate cursor movement; cut genuine scrolling dead time if needed.
- Do not place an SOS call, join strangers' rooms, show private notes or pass simulated vitals off as sensor data.
- A sensor demo is optional. If included, use a real connected device or explicitly show the SIMULATED label.
- A personal origin story can replace part of the problem narration if truthful. Do not invent a family member or testimonial.
- Final video: public YouTube/Vimeo URL, 1–3 minutes. Rules: https://www.congressionalappchallenge.us/wp-content/uploads/2026/05/2026-CAC-Rules.pdf
